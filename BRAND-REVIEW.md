# Аудит власного стилю PRGRSS

Дата: 29 жовтня 2026.

Основа — наявний інтерфейс PRGRSS і [власний дизайн-код](DESIGN-CODE.md). Скіл `.agents/skills/brand-guidelines` адаптовано для цього бренду зі збереженням атрибуції та ліцензії джерела.

## Знахідки та виправлення

- Зелена палітра, Geist та Ethnocentric утворюють наявну власну ідентичність. Палітру й шрифти Anthropic прибрано; початкові кольори браузерної панелі й PWA повернено до кольорів PRGRSS.
- Другорядний текст світлої теми мав контраст приблизно 4.49:1 на фоні сторінки. Відтінок змінено з `#6b756c` на близький зелено-сірий `#657064`, що дає приблизно 4.86:1.
- Input, Textarea та SelectTrigger використовували декоративний `border-border`. Межі полів переведено на окремий `border-input`; для обох тем підібрано контрастніші зелені відтінки без посилення меж усіх карток.
- Для заголовка входу збережено зменшений мобільний розмір. Основний шрифт заголовків знову Geist.
- Збережено українську доступну назву кнопки закриття пропозиції встановлення, `type="button"` та `role="alert"` для помилки входу.

## Межі аудиту

`pnpm run ci` пройшов: TypeScript, ESLint і production build. Залишилися 5 наявних попереджень Fast Refresh і попередження про розмір JS bundle. Валідатор скіла також пройшов.

Розрахований контраст другорядного тексту на фоні сторінки — 4.86:1 у світлій темі та 7.39:1 у темній. Межі полів на фоні сторінки й картки — щонайменше 3.04:1 в обох темах.

Контраст суцільних токенів перевіряється обчисленням відносної яскравості WCAG. Це не повний аудит доступності: прозорі поверхні, інші контролі та фокус потребують перевірки в браузері.

Мобільна візуальна перевірка попередньої ітерації не завершилася через зависання автоматизації браузера. Захищені екрани без авторизованої сесії візуально не перевірені. PWA-іконки та splash screens залишено в наявному власному оформленні.
